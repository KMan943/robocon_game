# robocon_game

# install libraries
`` sudo apt install build-essential cmake libglfw3-dev libglm-dev libglew-dev libgles2-mesa-dev libgl1-mesa-dev``

# build
`` mkdir build ``
`` cd build ``
`` cmake .. ``
`` make ``

# run 
`` cd build ``
`` ./MyGame ``

# recommended
install the **Cmake Tools extension** and the **Shader languages support for vs code** extension for ease of use
